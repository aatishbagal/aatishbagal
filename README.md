### Synapt Toolchain

A Ctrl+Space launcher that finds files and apps through a layered search pipeline (Bloom filter, prefix trie, tantivy full-text, fuzzy fallback), then pulls files straight off paired devices over the LAN. Pairing is secured with X25519 verification and ChaCha20-Poly1305 transfers. Ships signed, notarised installers for Linux, Windows and macOS from one pipeline, alongside **SynaptClip** for synced clipboard history.

### Traceway

A multi-tenant bug reporting and diagnostics platform with an organization and project dashboard, issue tracking, feature voting, community forums, and release management. Backed by a public REST ingestion API with Firebase Auth, Cloudflare R2 attachments, Upstash Redis rate limiting and realtime over Socket.IO, with a Flutter SDK as the first reference client.

### RoadAware

A crowdsourced road hazard reporting system using motion-sensor auto-detection and GPS to alert drivers of nearby hazards in realtime. Includes a dedicated windshield HUD mode, with a computer-vision dash interface for lane and collision warnings in development.
